# 项目背景与目标

> 本页整合自 Scott 仓库 `DEFI---RWA---/RWA理财/README.md` + `PRD/PRD-RWA理财-快照-v81-2026-07-31.md`
> 整理时间：2026-07-31

## 一句话背景

Binance Web3 Wallet 现有 DeFi Earn 模块只覆盖链上原生收益（Staking / LP / Lending），缺少 RWA 类产品。本项目在 DeFi 模块内新增 **RWA Earn** 入口与完整投资流程，一期接入 7–10 个 RWA 协议，目标 **2026 年 8 月底完成数据对接上线**。

## 需求背景（PRD 原文口径）

- RWA 赛道链上流通总值已达 **$34.19B**，月增 3.49%；BlackRock BUIDL 单月增长 28.44%，机构入场信号明确
- 现有 DeFi Earn 缺 RWA 类高收益产品

## 目标

1. DeFi 模块内新增 RWA Earn 产品入口和完整投资流程
2. 支持 **Locked（定期）** 和 **Flexible（活期）** 两种产品类型
3. 一期接入 **7–10 个 RWA 协议**，提供完整质押赎回、持仓管理体验
4. 为用户提供底层资产透明度（资产类别、管理人、托管方、收益来源）+ 风险信息，建立信任

## 数据侧新增需求（本仓库调研的直接动因）

RWA 理财相比普通投资品，数据侧需要新增：

| 需求 | 说明 |
|------|------|
| NAV 汇率曲线 | LSD 汇率变化**天级打点**，需历史回溯；从合约 `convertToShares / convertToAssets` 解析存库 |
| APY 曲线 | 与普通投资品一致，解析时自动获取 |
| Total Earnings / Yesterday Earnings | PNL 相关，后端聚合计算（当前快照 − 历史节点），Jackson / Kevin 侧统一算；**允许负值**（NAV 可能跌） |
| 赎回中状态 | 需返回 **request ID** + 交易结果状态 |
| 持仓数据 | 普通投资品解析自动覆盖，含 underlying 兑换数量 |
| 已结束投资品 invested 字段 | 取周期内**最高 balance**（持仓峰值）+ tooltip 说明 |
| Campaign Bonus | 有活动时展示 bonus，去掉 APY，改展示 earned + bonus |
