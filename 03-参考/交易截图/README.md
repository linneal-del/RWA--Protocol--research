# 交易截图存放处

按 [交易采集-操作清单与记录表.md](../交易采集-操作清单与记录表.md) 的命名规则放在这里：

```
<协议>-<序号>-<类型>.png

例：DMZ-01-approve.png
    DMZ-02-mint.png
    DMZ-03-dividend.png
    Nest-04-redeem-instant.png
    Ember-05-shares-received.png
```

每笔操作至少两张：**确认页**（点最终按钮前，能看到金额/费用/条款）+ **成功页**（能看到 hash 或"查看交易"链接）。

⚠️ 不要用系统默认的「截屏2026-08-03 15.51.18.png」——事后完全对不上是哪一步。
