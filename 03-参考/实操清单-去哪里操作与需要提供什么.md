## ⚠️ 动手之前先看这三条

### 1. 大部分协议其实不用花钱

我需要的是**合约地址 + 链**。这两样在多数产品页上**打开就能看到**，不需要真交易。

**真交易只对下面这一个是必需的**：
- 🔴 **DMZ rAI** —— 我需要看"每周派息那笔 USDT 是怎么发的"，这必须有真实持仓才会产生

其余 6 个，**零成本三步**就能拿到我要的东西：

| 步骤 | 做什么 | 能拿到 |
|------|-------|-------|
| **① 打开产品页截图** | 找页面上的 "Contract / 合约地址 / Token Address" 那一栏 | 合约地址 |
| **② 连钱包但不申购** | 连上后看它要求切到哪条链、下拉框里有哪些链 | **真实链**（能直接终结 Nest 和 Ondo 的链冲突） |
| **③ 看官方 docs 的地址页** | 多数协议 docs 站有 "Contracts / Deployments / Addresses" 页 | 全链地址清单 |

📌 **建议先做这三步，再决定要不要真交易。** 能省钱、省 gas，而且快。

### 2. 🔴 OpenTrade 那个链接，先别连钱包

主表里 OpenTrade 的产品页是 **`primeplusvault.lovable.app`**。

`lovable.app` 是一个**快速建站平台的域名**，不是 OpenTrade 的主域（他们官网是 `opentrade.io`）。这可能是项目方做的临时页面，也可能不是。

→ **在找 Cece 确认这个页面是官方的之前，不要连钱包、不要授权、不要转账。** RWA 产品的钓鱼站是真实存在的。

### 3. 强烈建议：用一个新的专用钱包

如果你决定真交易，**新建一个空钱包专门做这件事**，理由有三个：

| 理由 | 说明 |
|------|------|
| **保护隐私** | 钱包地址是公开的。给我主钱包地址 = 公开你的全部持仓、全部交易历史、总资产 |
| **数据更干净** | 专用钱包里只有本项目的交易，我拉历史时没有噪音，解析更准 |
| **限制风险** | 这些是真实的链上理财产品，有本金风险；且部分产品**赎回不是即时的**（见下表） |

## 二、成本预估（真交易的话）

| 链 | 涉及协议 | gas 币 | gas 成本 |
|----|---------|-------|---------|
| **BNB Chain** | DMZ、Nest、Unitas、Ondo | BNB | 很便宜，几毛到几块钱一笔 |
| **Ethereum 主网** | Ember、Re（×2）、OpenTrade | ETH | **较贵**，按行情几美元到几十美元一笔 |

**申购金额**：验证解析逻辑**只需要最小额**，不需要投大钱。但注意：
- 部分产品有**最低申购额**限制（PRD 里举的例子是 1,000 USDC 起投），页面上会写
- Unitas 需要 XAUt，得先换币，多一步成本
- 🔴 **这些是真实理财产品，有本金风险**；且 Re reUSDe 短期赎不出来

## 五、安全底线（重复一遍，很重要）
