| 项 | reUSD | reUSDe |

| 合约类型 | **EIP-1967 可升级代理**（bytecode 仅 133 字节） | **EIP-1967 可升级代理** |
| 实现合约 | `0xb5276c436f65913cd5332de745d04fedeb4a21d4` | `0xb5276c436f65913cd5332de745d04fedeb4a21d4` |

### 🔴 三个必须让中台知道的结论

**1. Re 不是 ERC-4626，NAV 不能从合约内部取**
我原先在 `Re.md` 里写「NAV 从 `convertToAssets` 取」，**这是错的**（当时按 A 类通用模式推断的）。实测四个 4626 函数全部 revert。
→ 产品页上 PRICE 那一栏明确标注 **"NAV Oracle"**，说明 **NAV 是外部预言机喂进来的**（与官方文档"Fireblocks 金库余额每日推送 Chainlink"一致）。
→ **必须向项目方要 NAV oracle 的合约地址 + 读取方法**，这是 Re 接入的第一个前置条件。

**2. reUSD 和 reUSDe 共用同一个实现合约**
两个代理都指向 `0xb5276c…21d4`。
→ 好消息：**一套解析适配器能同时覆盖两个代币**，边际成本很低。

**3. 可升级代理 = 新增一条风险**
项目方可以随时替换实现合约逻辑。
→ 要写进 Risk Tab；也建议中台**监控实现合约地址变更**（proxy slot `0x360894a1…82bbc`），变了要告警。

#### 🔴 Ember 的「每日批处理」会打破 PRD 的申购流程

页面明确写着 **Daily Processing，Shares Received: After processing**。意思是：

```
用户签完申购交易 → 钱已扣走 → 但拿不到 share
                → 等到下一个处理时点（每天 00:00）→ 才铸出 share
```

**这段真空期里会发生什么**：
- 用户的 USDC 已经没了
- 但凭证代币 balance 还是 0
- → **按我们现在的解析逻辑（balance × NAV），用户持仓会显示为 0**

**对 PRD 的直接冲击**：
- **4.6.1 Step 4「申购成功」** 展示"质押金额 900.28 USDC" —— 但此刻链上并没有对应持仓
- **4.5.2 Portfolio Tab** 展示规则是"有持仓才展示" —— 用户申购后打开详情页会看到空状态
- PRD 目前**只为「赎回中」设计了中间态，没有为「申购中」设计**

→ 🔴 **需要新增一个「申购处理中（Pending Subscription）」状态**，或者中台解析要能识别"已存入但未铸份额"的待处理金额。**建议找 Marcus 单独过一次。**

### 结论与建议

1. **前端绝对不能用 CSV 里的静态数字**。TVL / APY 必须走实时接口（PRD 本来也是这么设计的：APY / NAV 由 API 实时获取）

## 六、复现方式（给中台同学）

```bash
# 查代币基本信息（Ethereum 主网，无需 API key）
curl -s -X POST https://ethereum-rpc.publicnode.com \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"eth_call","params":[
       {"to":"0x5086bf358635B81D8C47C66d1C8b9E567Db70c72","data":"0x95d89b41"},"latest"]}'
# 返回的 hex 尾部即 symbol 字符串

# 查是否可升级代理（EIP-1967 实现槽）
curl -s -X POST https://ethereum-rpc.publicnode.com \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"eth_getStorageAt","params":[
       "0x5086bf358635B81D8C47C66d1C8b9E567Db70c72",
       "0x360894a13ba1a3210667c828492db98dca3e2076cc3735a920a3ca505d382bbc","latest"]}'
```

**常用 selector**：`name()` `0x06fdde03`｜`symbol()` `0x95d89b41`｜`decimals()` `0x313ce567`｜`totalSupply()` `0x18160ddd`｜`asset()` `0x38d52e0f`｜`totalAssets()` `0x01e1d114`｜`convertToAssets(uint256)` `0x07a2d13a`｜`previewRedeem(uint256)` `0x4cdad506`

> ⚠️ 部分公共 RPC（如 `eth.llamarpc.com`、`cloudflare-eth.com`）会拦请求或报 Internal error；`ethereum-rpc.publicnode.com` 和 `1rpc.io/eth` 实测可用。用 Python 请求时记得带 `User-Agent`，否则被 403。
